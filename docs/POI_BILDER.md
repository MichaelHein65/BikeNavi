# Clay-Motive für die POI-Seite

Erstellt am 15. Oktober 2026 mit dem eingebauten Imagegen-Werkzeug, nicht mit dem API-/CLI-Fallback. Stilreferenz: vom Nutzer bereitgestellter BikeNavi-Startbildschirm. Das private Referenzbild selbst wird nicht in das Repository kopiert. Transparenz bleibt erhalten. Die ausgewählten Originalausgaben werden unverändert in die App-Assets kopiert.

## fuel

Asset: `ios/BikeNavi/Assets.xcassets/POI_fuel.imageset/fuel.png`

Prompt:

```text
Use case: stylized-concept. Asset type: standalone illustration for a native iPhone POI tile. Input image is STYLE REFERENCE ONLY. Transform the reference into one isolated illustration, matching exactly the handmade clay/plasticine miniature style of the bicycle, car and hiking gear: tactile matte clay, softly rounded sculpted forms, detailed three-dimensional objects, subtle handmade seams, soft studio light from top left, warm friendly colors, grounded soft contact shadow. Subject: A friendly freestanding miniature fuel pump, muted turquoise blue and warm orange details, black flexible hose and nozzle, blank cream display, tiny rounded base. Center the whole object in a square canvas, occupy roughly 80% of image width and height with generous clear margins. Transparent background with true alpha, no backdrop, no tile shape, no frame, no UI, no captions, no text except the P for parking. Do not draw a flat glyph or SF Symbol. Return one finished image asset.
```

## Korrektur des Tankstellenmotivs

Die erste Fassung enthielt irrtümlich ein P. Die ausgewählte Fassung ersetzt es mit einem Kraftstofftropfen. Verwendeter Bearbeitungsprompt:

```text
Edit only the fuel pump illustration: remove the raised letter P from the round orange badge and replace it with one simple cream-colored raised fuel droplet shape. Absolutely no letters, numbers or text anywhere. Keep the pump, hose, nozzle, colors, matte clay texture, lighting, framing and genuine transparent background unchanged.
```
