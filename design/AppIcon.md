# BikeNavi App-Icon

Erstellt am 19. September 2026 mit dem eingebauten Imagegen-Tool (Imagegen-Skill, kein CLI-Fallback). Das ausgewählte Original liegt in `AppIcon-source.png`. `scripts/prepare_app_icon.py` skaliert es für das iOS-Asset auf 1024 × 1024 Pixel; der Hintergrund ist deckend. ## Verwendeter Prompt

Use case: logo-brand. Asset type: final iOS app icon for BikeNavi, a bicycle touring navigation app. Create one polished minimalist flat graphic: a bold cream bicycle symbol combined naturally with a lime navigation arrow pointing north-east, on a rich deep forest green background (#195945). Strong distinctive silhouette legible at small home-screen sizes. Centered balanced composition, generous safe padding around the mark, crisp simple geometry, subtle tonal depth only in the background. Color palette: forest green, warm off-white (#F5F7ED), fresh lime (#D1F06B). Full bleed opaque square 1024 by 1024 pixels; background fills all four corners. No rounded square border or outer margin (iOS masks the icon itself), no text, no letters, no watermarks, no device mockup, no scenery, no gradients on the main symbol. Deliver exactly the icon artwork as a PNG.
